# Guidance

Put durable context here when it should apply across multiple runs for this package or project.

Files:
- `enterprise.md` - enterprise/client standards, terminology, compliance expectations, delivery rules.
- `domain.md` - domain-specific concepts, metrics, regulatory context, business rules.
- `project.md` - project scope, known systems, stakeholders, assumptions, constraints, accepted decisions.

The agent reads these files as standing guidance. They should be concise and curated.
