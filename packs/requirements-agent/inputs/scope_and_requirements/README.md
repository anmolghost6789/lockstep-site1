# Scope and Requirements

Put active project scope and requirements evidence here:

- Project charter
- Scope document
- Existing BRD/FRD/URS draft
- Business rules
- Stakeholder-approved requirement fragments
- Requirement spreadsheets or exports

The agent treats these as primary evidence for UC, KBQ, KPI, DR, BRD, URS, FRD, and Jira story generation.
