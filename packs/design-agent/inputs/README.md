# Inputs

Place run-specific files into the most relevant sub-folder before starting /start-design-run.

- instructions/ - user directives and run-specific guidance
- requirements/ - BRD, FRD, URS, requirements exports, or equivalent
- source_inventory/ - source system/table inventory and schemas
- additional_documents/ - rules, KPIs, glossaries, examples, and supporting docs

README.md files and placeholders are package guidance, not run input evidence. If every input category contains only README.md or placeholder files, /start-design-run must not create a run.
