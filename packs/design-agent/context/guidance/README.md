# Guidance

Persistent guidance organized by authority tier. User instructions are intentionally not stored here; run-specific directives belong in `inputs/instructions/`.

Authority order from broadest to narrowest:

1. `enterprise_context/`
2. `domain_context/`
3. `project_context/`
4. `inputs/instructions/` user instructions for the active run

Lower-tier guidance may override higher-tier guidance only with explicit evidence or human confirmation according to the package conflict-resolution rules.
