# `context/reference/`

Reusable reference material the Build Agent can cite, pattern-match against, or use as exemplars. Reference content is not authoritative requirement input — it's "here's how we usually do it" material.

## Example contents

- **`databricks_patterns_reference.docx`** — canonical patterns (medallion layout, DLT pipelines, autoloader configs) used as exemplars for `generate-pipeline`.
- Internal style guides, anti-pattern catalogs, or vendor cookbooks the team wants the agent to lean on.
