# Claude Project Subagent Memory

This folder is for Claude Code project-scoped subagent memory. It is separate from Build Agent package memory in `runs/_memory/`.

Use this only for concise, reusable, non-confidential calibration notes for named subagents (input-analyzer, plan-generator, artifact-writer, build-evaluator, learnings-curator). Do not store raw inputs, transcripts, secrets, client-specific facts, Jira issue keys, or one-off assumptions.
