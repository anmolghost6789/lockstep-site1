# STTM (Source-to-Target Mapping)

Place your source-to-target mapping files here.

Supported formats: XLSX (recommended), CSV, DOCX, PDF, MD

For best results, use the golden template in `templates/STTM_TEMPLATE.xlsx`. The template has a `table_tracker` sheet plus per-table sheets with summary and detail blocks. Template conformance accelerates parsing but is not required.
