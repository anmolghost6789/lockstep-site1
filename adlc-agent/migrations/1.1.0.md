# Migrating to 1.1.0

1. Run `pack.py upgrade`; merge any `.upstream-1.1.0` files it reports.
2. Review the new `config/governance/agent_catalog.json` with your platform team and approve agents.
3. Set `gate_mode` in `config/project_config.json` (`github` is the new default), then run `setup_codeowners.py` and apply branch protection.
4. Optional: set `telemetry.push` to `true` to share delivery metrics with your registry.
